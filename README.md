## Overview

Angel's Refining adds multi-stage ore washing, floatation, and smelting chains that produce higher metal yields from raw ore at the cost of more complex factory layout, integrating with Bob's Mods.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Angels Refining** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Ore Sorting** | Crush and sort mixed ores into pure streams before smelting |
| **Floatation Cells** | Wet processing separates trace metals from primary ore streams |
| **Electrolysis** | Electric refining stages produce exotic metals unavailable in vanilla |
| **Bobs Integration** | Full compatibility with Bob's Metals, Chemicals, and Intermediates |
